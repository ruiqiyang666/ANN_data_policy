# 第二版现场接入步骤

本轮交付的是本机训练、冻结评估和历史加工锚点回放。第二版没有在现场服务器执行训练，没有接通现场数据接口，也没有发送实际换枪指令。第一版曾在服务器复现的记录，不能当作第二版已经部署的证据。

三台服务器在同一交换机，建议按以下数据流接入：

```text
Booth2 现场接口 → 应用服务器采集 → 数据服务器原始事件与预测留档
                         ↓                     ↑
                    ANN 服务器推理与告警 ────────┘
                         ↓
                    应用服务器展示提醒
```

## 1. 应用服务器：核对接口并采集

先核对真实协议、地址、端口、账号权限、设备时区、每字段刷新周期和质量码；不要从一张界面截图推定整表同步采样。确认设备命名空间是 `HA.Booth2.Plasma2`，不混入 Booth1 的参考电压。

每个采集点至少保存：设备、标签、数值、源时间 `source_timestamp`、实际接收时间 `received_at`、原始质量码。向 ANN 服务提供原点之前已经收到的点。迟到数据仅影响后续原点，不回填或重画过去预测。

| 模型传感器字段 | 现场对应字段 |
| --- | --- |
| `Voltage`、`Current`、`Power` | 同名标签 |
| `Station_1`、`Station_2` | 同名标签；负转速仍可表示加工 |
| `Feedrate_1`、`Feedrate_2` | 同名标签；由当时正送料状态确定活动料斗 |
| `Press._Hopper_1`、`Press._Hopper_2` | `Press_Hopper_1`、`Press_Hopper_2` |

`Gun_ID.DATA`、`Gun_Hours`、`Ignitions` 预留为未来元数据。`Gun_ID.LEN` 只是字符串长度。历史没有连续采集这些字段，本轮不能把事后换枪记录回填成训练输入；接入后也应先核对计数何时增加、何时清零，不能直接替代日历时间或安装周期。

## 2. 数据服务器：保留原始时间与当时预测

分开保存原始事件、质量与接收时间、确认的维护记录，以及每个预测原点的评分、阈值、模型版本、告警状态。生产结束后的完整产品均值和失败标签放入独立评估表，不作为此前预测的输入。保留实际更换时间范围，不把候选停枪范围写成精确拆装秒。

为重放保留不可变原始记录和追加式预测台账。相同原点不能覆盖已保存评分；模型更新使用新版本号。缺口、未知质量、排除工艺和服务器重启都要有明确标记，不把缺失填成正常零值。

## 3. ANN 服务器：固定模型与相同告警规则

部署本工程的冻结模型、预处理器与 `artifacts/frozen_config.json`，先复现本机记录中的结果。不要将旧版的目标、权重或阈值与第二版混用。训练源数据和事件真值只用于离线复现，不下发给实时推理器作为特征。

当前 `src/inference.py` 的 `StreamingPredictor.push(...)` 接收已经准备好的、逐个到达的加工原点，包含九个传感器值及真实过去 60 秒电压均值／标准差；它不是完整现场采集器或原始 PLC HTTP 服务。现场适配器仍需实现并验证字段质量、陈旧度、加工确认与原始统计聚合，不能直接把整秒原始点当成同口径输入。

现场适配器应使用每秒到达的事件维护状态；正式评分沿用已有历史的实际加工 10 秒原点。开始加工须确认至少 3 秒；正转、1—2 秒换向、反转属于同一件产品。只有电流、功率与转台状态符合加工条件，且输入质量合格时才产生对应评分。长时间停机和跨夜不伪造加工原点。

历史窗口只向过去取值，并保留缺失掩码。原始字段陈旧上限必须按真实刷新周期核对；质量坏、点未收到或过旧时应缺失。不能用未来读数插值回填。换枪经现场确认后重置历史和告警状态，不能仅凭电压回升猜一次更换，也不能将周期编号当作模型数值输入。

第二版固定的核心告警规则：两个连续越阈原点、间隔不超过 90 秒才确认；10 分钟没有满足信号时结束该次报警过程；重复报警受 30 分钟冷却限制。阈值以冻结配置为准，现场不能根据后来发生的失败时刻重新挑一次“最接近 20 分钟”的报警。

预警含义是末期风险提醒。终点 T 是最终连续失败第一件开始加工；至少提前 20 分钟是业务达标条件，不是每个原点固定输出“还剩 20 分钟”。本轮没有证明可自动触发换枪，也没有训练未来电压曲线预测。

## 4. 应用展示与上线前回放

应用展示当前风险、数据是否有效、首次有效报警时刻和模型版本。把风险提醒、事后完整产品判定及后续实测电压分开展示，避免将后续实测曲线当作预测曲线。

先用相同原点、相同输入顺序做离线回放，对照冻结台账的评分与报警时刻；然后进行现场只记录提醒的并行观察。第二版历史回放沿用离线已确认产品资格，不能代替对现场原始异步数据、工艺切换与质量门控的验证。待实际接口、时区、质量、采集延迟及维护确认机制核对后，再决定现场提醒流程。

验证使用的新现场周期应完整保留正常生产、预防性更换、误报、晚报和漏报。测试集合已经被历史实验部分查看；只有后续新增周期才能进一步检验泛化。送料、罐压不能借用电压末期成绩宣称已达标。
