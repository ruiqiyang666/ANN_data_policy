# 服务器配置核查命令

2026年11月4日。本机硬件足够首轮，以下命令仅在后续需要服务器时使用，当前未执行。沿用用户偏好：由用户在VS Code Remote SSH终端或普通SSH终端运行。它们只查询配置，不安装软件、不训练、不停止panel。

先从本机连接：

```powershell
ssh dev@100.104.199.22
```

连接后在服务器Linux终端运行：

```bash
hostname
lscpu
free -h
nvidia-smi --query-gpu=name,driver_version,memory.total,memory.free,memory.used,utilization.gpu --format=csv
df -h /home/dev/Zhang/Phase2 '/home/dev/Zhang/private/Real-time Data' /home/dev/Zhang/private/results
python3 --version
python3 -m pip show torch numpy pandas pyarrow scikit-learn
```

若上述当前解释器已安装PyTorch，再查询该环境CUDA支持：

```bash
python3 -c 'import torch; print("torch:", torch.__version__); print("CUDA build:", torch.version.cuda); print("CUDA available:", torch.cuda.is_available()); print("devices:", torch.cuda.device_count()); print("arches:", torch.cuda.get_arch_list() if torch.cuda.is_available() else [])'
```

如果宿主机Python没有PyTorch，只能说明当前环境未配置，不代表服务器不能训练。应先核对实际训练环境；不进入panel容器安装训练依赖或占用其运行进程。若服务器没有NVIDIA GPU，也不因它被称为服务器就默认其训练更快。
