# 28参数模型训练与评估

执行更新（2026年11月4日）：**首轮训练、冻结测试和产物核验已完成**。结果见[首轮训练结果.md](首轮训练结果.md)。风险主候选为 `hist_tree`，寿命仅弱证据拟合，模型目前供实验回放，未接入旧看板或用于自动换枪。全部新产物位于本目录。

原规划文档保留设计背景，实际分区和标签数以 `data/20261104_v1/windows_ready.json`、`rul_label_audit.json` 为准。独立周期隔离后校准集为空；寿命终点仅弱证据，不宣称已经验证自然失效时间。60秒后压力预测不在本轮范围。

2026年11月4日，根据用户最新要求，训练输出与现有看板对齐：剩余带电寿命、剩余加工件数、寿命范围、当前异常、未来5分钟异常概率及类型、预计异常发生时间、喷枪和料斗健康度及相关解释。取消60秒后压力预测及其预测趋势；压力仍保留为28参数输入、当前测量展示和压力异常判断依据。

公司无法提供更多标注，本轮以现有资料开展内部复核和标签整理，不等待新增标注。现有9月12日至10月23日标注包含28个异常片段；按公司明确纠正的1件压力误判调整，涉及58件异常产品。按低压停机及复机恢复证据推定换枪5次，尚不是全训练时段的已确认自然失效总数。详见数量核对文件。

用户已明确：寿命目标是预测电极距离自然失效还剩多久，再据此安排提前换枪。历史实际换枪时间用于识别周期和干预，不能一律作为自然失效时间。已确认仍可工作时的人为提前换枪保留为尚未观察到自然失效的记录；未来按模型预测提前换枪也采用同样处理。

自然失效剩余时间和未来300秒异常估计是主要训练目标。未来若干件产品失败预测作为辅助任务和评估，不替代看板输出。预测自然失效时间、建议换枪时间和实际换枪时间分别保存。

本机RTX 5070 Ti Laptop GPU约12GB显存、约32GB内存，已实际运行首轮模型训练。使用目录内 `.venv` 入口及既有系统包只读引用，环境不是完全封闭的依赖环境；版本记录见执行产物。不连接服务器，不修改现有看板。所有有效结果都来自本轮28参数数据，未加载旧模拟模型。
