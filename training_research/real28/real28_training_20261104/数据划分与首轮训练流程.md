# 数据划分与首轮训练流程

2026年11月4日方案版。本文件具体落实已确认目标：用主设备28参数预测电极自然失效的剩余带电时间和件数，配合未来300秒异常、当前异常和健康输出；利用预测指导提前换枪。人为提前更换不作为自然失效终点。按用户最新要求取消60秒后压力预测，压力保留为输入和异常类别，当前压力直接测量展示。

本轮只读取既有审计和标注，整理训练协议。未执行原始数据处理、标签重算或训练程序。以下超参数是首轮实验的预设起点，不是已经验证的最优设置。

用户随后要求调研本机配置及前沿算法。已完成只读硬件/Python/CUDA元数据检测和官方资料调研：本机约12GB显存、32GB内存，首轮优先本机。方案增加自监督预训练、冻结表示的低维寿命拟合与有限的较新模型对照，依据见[本机配置与算法调研](本机配置与算法调研.md)。没有运行GPU算子基准或安装软件。

公司无法提供更多标注。标签整理、规则修订与内部复核全部基于现有材料，不等待公司追加确认。现有标注计数及5次低压后换新推定见[现有异常与换枪数量核对](现有异常与换枪数量核对.md)，这些计数不等于全时段最终可用训练标签数。

**一、按时间和电极周期划分**

范围为2026年8月15日至10月23日，只使用主设备四个日期目录。Voltage Sample不参与训练、归一化、模型选择、校准或最终测试。

| 分区 | 日期，含首尾日 | 原始记录数 | 占全部原始记录 | 用途 |
| --- | --- | ---: | ---: | --- |
| 训练 | 8月15日—9月29日 | 3,913,764 | 72.45% | 拟合预处理和模型参数 |
| 验证合计 | 10月4日—10月9日 | 452,988 | 8.39% | 模型选择、告警阈值及区间校准 |
| 最终测试 | 10月10日—10月23日 | 1,035,417 | 19.17% | 冻结后评价，不能用于调参 |
| 合计 | 有记录的65天 | 5,402,169 | 100% | 约898 MB原始CSV |

记录数由既有`reports/real_data_review_20261031/audit.json`逐日统计汇总，不是本轮重新扫描的结果；百分比独立四舍五入。9月30日至10月3日没有记录，10月18日也没有记录。表中是清洗、周期隔离、窗口构造前的原始行数，不能称为最终训练样本数。

验证区间进一步预分为：10月4—7日进行早停和模型选择，共294,803条原始记录；10月8—9日用于概率、告警阈值和寿命区间校准，共158,185条。实际可用周期可能很少，不能仅凭这两天数据宣称获得可靠的90%寿命覆盖率。

先生成修订后的周期与事件表，再冻结分区清单。采用以下边界规则：

1. 同一已确认电极周期只能归属一个分区，失败事件前后的重叠窗口也不能拆入不同分区。该规则覆盖训练、模型选择、校准和测试。
2. 若周期跨过预设日期边界，优先归属较后的分区；只使用该分区日期内的样本，较早部分从训练或调参中排除。不能把未来部分搬回训练集。新分区开头的历史不足按缺失上下文处理，不用跨区数据拟合特征。
3. 输入历史与未来300秒目标分别检查边界。即使短窗口没有跨界，RUL监督也不能读取下一分区的失效结果作为训练真值。
4. 为保持同周期隔离，跨界周期不采用“前半段做删失训练、后半段做测试”的安排。这样虽然能构造损失，却不是独立周期验证。
5. 周期身份不清楚时保留时间块隔离和事件隔离，并将寿命的独立周期验证状态标为未证实。不能编造枪号或按文件夹边界换枪。
6. 若周期隔离后某分区没有可用自然失效事件，报告该项无法独立评价；可在建模前重新制定并记录周期分界，不能在看到模型测试成绩后调整切点。

最终产出每个分区的文件数、原始行数、产品数、窗口数、自然失效周期数、提前更换删失周期数、未知周期数，以及每个输出的有效标签数。目前这些最终数量尚未生成。

**二、先生成三类标签**

第一类是产品与工艺事件标签。按公司11月3日回复修订131件缺点样本、P003507压力结果、早期低压不稳定及批次停机规则。补齐8月15日至9月11日产品，保留原241件关注样本的编号映射。Station分段与活动料斗口径先抽查，再生成完整产品表。

第二类是自然失效与提前维护标签：

| 历史情况 | 时刻t的训练信息 |
| --- | --- |
| 后续自然失效时刻可靠 | t至失效之间的累计带电小时、完成产品数，以及失效事件标志 |
| 自然失效只定位到一个区间 | 剩余时间或件数的上下界，保留区间监督 |
| 电极未自然失效就提前换下 | t之后已确认未失效的运行时长和产品数，保留右删失监督 |
| 数据结束时电极仍正常 | 同样保留截至观测结束的未失效信息 |
| 是否换枪、是否失效或期间运行状态不明 | 不生成精确RUL；仍可对其他具有有效标签的任务使用该样本 |

例如，时刻t之后又带电运行2小时便人为提前换枪，只知道当时的自然剩余带电寿命超过已观察的2小时，不能填成正好2小时。剩余件数用实际可追溯产品计数，不用固定每小时产量换算。

提前更换可能由恶化趋势触发，应保存当时原因和工况。删失不是自动补出自然寿命的方法；需要自然失效事件共同约束模型，并按更换原因检查模型偏差。

第三类是预测窗口标签：

- 未来异常：检查自然时间(t, t+300秒]内的首个新工艺异常事件，保存是否发生、事件类型和时间位置。产品均值类事件初版按结果首次可判定时间定位，并另存喷涂起止用于提前量评价。
- 窗口完整且无事件时标无异常；未观察满300秒且没有事件时不能标完整负例，可以只利用已观察前缀。
- 当前异常：依据时刻t已经可判定的事件状态构造；产品尚未结束时不能把其完整均值当作当时已知的异常。
- 压力越界保留在当前异常及未来300秒异常类型中；两个物理料斗压力继续作为输入，不生成未来压力数值目标。
- 健康度：保留分支和字段，但须有明确评分依据或标识为弱监督的标签。没有标签的健康头不输出未经训练的分数。

**三、训练样本怎样构造**

首轮默认以最近120秒的28参数序列为短期输入，保留1秒分辨率；60秒窗口作为唯一的窗口长度对照。训练默认每10秒选一个预测时刻，在线推理可每秒更新。取窗步长不是原始采样间隔。

以12:00:00的一条样本为例：

| 内容 | 使用范围 |
| --- | --- |
| 短期输入 | 11:58:01—12:00:00，共120个期望时间点，28参数 |
| 历史统计 | 12:00:00以前的5、15、60分钟趋势及已经完成的产品统计 |
| 5分钟风险目标 | 12:00:00之后至12:05:00是否出现新事件 |
| 自然失效寿命目标 | 有可靠后续失效时按带电时间与产品数计算；提前更换则只提供未失效观察界限 |

只使用t及以前的输入。复机后的电压、后来的人工确认、未来产品完整均值和更换原因不能回填为t时刻已经知道的特征。

输入额外带质量掩码、时间间隔、活动料斗和工况标记。仍保留两个料斗原始物理通道，两个转台与料斗不强行一一对应。气体、电气、冷却、送料和环境参数均保留，再通过训练内的特征消融判断贡献。

少量缺点可采用仅依赖过去值的短缺口处理并保留掩码；长缺口切断。归一化和填充值只在训练分区拟合。历史不足时提供已观察长度和掩码，不使用未来数据补满。长时间待机可以稀采样，但验证和测试保留真实工况分布。

每个电极周期及每个异常片段控制总权重，避免长周期或同一异常的密集窗口主导训练。10秒重叠窗口不能被当作独立设备故障来计算置信区间。

**四、首轮模型结构**

模型采用共享时序编码加任务分支，首轮主候选是小型Residual-TCN；先比较同结构不预训练与自监督预训练两版：

- 28参数序列和质量信息进入32通道的因果卷积编码器。
- 5个残差块，每块2个卷积，卷积核3，膨胀率1、2、4、8、16；单个末端表征可覆盖约125秒，能够覆盖默认120秒窗口。
- 5、15、60分钟历史统计和已完成产品特征经过小型全连接层，与短期表征融合。
- 融合表征连接自然寿命、剩余件数、未来300秒事件时间分布、异常类型、当前异常和有有效监督的健康分支。

现有模拟网络的实现可以参考，但不直接加载21参数模拟权重和旧归一化。新模型内部编码维数包含质量标记等派生输入，应与28个原始仪器参数明确区分。

自监督阶段只使用训练分区历史，在过去窗口内对原本有效的观测点施加约15%的短块遮挡并学习重建，最多20轮；原始缺失点不当目标。全部归一化及内部监测分区都局限于训练时段。先微调异常分支，再冻结编码器拟合寿命；寿命模型仅保留少量训练内确定的表示/物理特征及强正则，避免用几次事件优化整个网络。模型范围不自动代表经独立验证的寿命覆盖率。

自然寿命分支首轮采用参数化生存分布，例如条件对数正态AFT，输出剩余带电时间分布的参数；用分布中位数作为`rul_hours`点估计，区间另经校准评估。它能够同时学习准确失效、失效区间和提前更换的观察记录。选择该分布是便于首轮验证的建模假设，不表示电极寿命已被证实服从对数正态。

小时目标的三类损失分别为：准确失效使用事件密度的负对数；未失效到观察结束使用生存概率的负对数；失效区间使用落在该区间内概率的负对数。不能给提前换枪样本填一个猜测寿命再做普通均方误差。

自然失效已发生的时点由事件状态单独表达；寿命生存训练只取事件前尚未失效的时点，避免把零剩余时间直接放入正值分布的对数计算。区间事件还需保证预测时点确实早于失效区间，不能把失效状态不明的区间内样本当作确认未失效。

剩余件数使用独立的计数分布头和计数标签，不由小时预测直接换算。可将非负整数n的概率定义为连续生存函数在n与n+1之间的概率质量，未失效观察到c件使用仍可达到c件的生存概率；这样零剩余件数和删失计数都有明确处理。点估计与区间按该离散分布计算。

未来300秒划为10个30秒时间段，预测各段在此前未出现新事件条件下的事件风险。由同一分布得到未来5分钟总体概率及条件事件时间，另输出首个事件的类型。总体概率为1减去10段未出现事件概率的乘积。ETA只在风险达到验证后的显示门槛、且时间估计有效时显示；30秒分段的秒数显示不代表秒级精确定位。

当前异常和事件类型保留电压、送料、压力等子标签，允许同一事件有多个类型，不把这些工艺类别直接解释为旧模拟模型的机械根因。压力只参与输入、异常判定和当前测量展示，不设置独立的压力预测分支。

首轮必须同时建立简单对照：支持删失的低维正则化AFT、使用相同历史信息的简单异常风险模型及浅树模型。TCN必须与同一分区和同一监督口径的对照比较。小型PatchTST与Chronos-2-Small辅助特征按顺序加入，不对所有架构做大规模搜索。

**五、首轮训练配置**

| 项目 | 首轮预设 |
| --- | --- |
| 框架 | PyTorch，新28参数入口 |
| 短期窗口 | 默认120秒，对照60秒 |
| 训练取窗步长 | 10秒，按事件和周期控制权重 |
| 优化器 | AdamW |
| 初始学习率 | 预训练/随机初始化0.001；预训练编码器异常微调0.0001，任务头0.001；寿命阶段冻结编码器 |
| Weight decay | 0.0001 |
| Batch size | 128；实际显存不足时调小并记录 |
| 最多轮数 | 自监督20轮；有监督30轮 |
| 本机精度与取数 | 编码器BF16，生存/对数损失FP32；按索引取窗，DataLoader先用2个worker |
| 早停 | 模型选择集指标连续5轮未改善 |
| 学习率调整 | 模型选择集连续3轮未改善时减半 |
| 梯度范数上限 | 1.0 |
| Dropout | 0.1 |
| 首轮随机种子 | 42 |
| 重复性检查 | 在最终测试前确定方案，再用另外2个固定种子复训，报告波动 |

每个任务只对有效标签计算并平均损失，按阶段使用固定初始权重：异常阶段为300秒事件时间分布1.0、未来事件类型0.25、当前异常0.25；冻结表示后的寿命阶段为小时生存1.0、件数生存0.5。健康若有有效标签再单列损失和权重。没有有效标签时该项不参与优化，并记录该头未训练。权重仅允许在训练内滚动验证和模型选择集调整，首轮不使用寿命损失更新整个编码器。

异常阶段早停使用预先固定的验证目标组合，寿命阶段单独保存其可评价指标及逐事件结果。若某主要任务在模型选择集没有有效事件，就不能声称该任务完成了验证，也不能把缺失指标计成0误差。只有一个寿命事件时限制模型选择次数，不据此筛选大量超参数。

先完成基线、TCN无预训练及TCN自监督三组，再按顺序加入小型PatchTST和Chronos-2-Small对照。窗口默认120秒，结构明确后再比较一次60秒窗口。本机GPU已完成元数据检查，训练进程显存先预算约8 GiB；未运行训练或吞吐基准，实际峰值和耗时在执行时测量。服务器仅在实测资源或持续运行需求不合适时启用。

**六、训练、校准和测试的先后顺序**

1. 只读原始数据，在独立目录输出来源、产品、自然失效、提前更换和未知事件表，完成各任务标签覆盖统计。
2. 冻结时间、周期和事件分区，生成训练窗口。保存训练专用归一化参数，后续分区只应用这些参数。
3. 先训练简单基线；TCN分别比较无预训练和仅在训练时段自监督预训练的版本，先异常微调再冻结表示拟合寿命。按需逐个加入小型PatchTST及Chronos-2-Small对照。仅用10月4—7日的模型选择数据早停和选方案。
4. 在10月8—9日的校准块确定概率显示门槛、预警合并规则及寿命区间方法。校准也需周期隔离；事件过少时报告未充分校准，不挪用测试数据。
5. 冻结模型、预处理、阈值、区间方法和随机种子评估安排，最后才对10月10—23日进行测试。
6. 测试逐事件报告实际提前量、漏报和误报；寿命同时报告自然失效周期上的误差及能处理删失的评估。不可直接将所有提前更换时刻作为寿命真值计算MAE。
7. 生成看板兼容产物：模型、28参数契约、归一化、任务可用状态、单位、阈值、版本和独立评估。模型指导的提前换枪记录今后继续按干预处理，不回写为自然失效真值。

寿命分布区间要区分“模型给出的分位区间”和“经独立数据验证过覆盖率的区间”。若只在已自然失效的完整周期上校准，不能直接宣称对所有提前更换周期也保持相同覆盖率。先保留实际证据，避免沿用旧模拟模型的90%范围承诺。

**七、最终要看哪些结果**

- 自然失效剩余小时MAE和剩余件数误差，按完整周期汇总，不按密集重叠窗口虚增独立样本量。
- 寿命区间覆盖、宽度及适用范围；对提前更换记录使用支持删失的损失和评价，不伪造误差真值。
- 未来300秒风险的PR-AUC、概率校准、事件召回、每100小时有效运行的误报数。
- ETA在真实未来事件窗口上的误差，以及所有事件中未提前报出的比例；不能只报告成功预警的时间误差。
- 第一件失败发生之前提前了多少秒、多少件，而不是等连续多件失败后才算预警成功。
- 当前异常与未来异常类型按电压、送料、压力分别报告；压力事件只有单个片段时，明确该类泛化效果尚不能可靠估计。
- 健康度只有在有有效监督时报告精度；其他情况下明确该输出未完成验证。
