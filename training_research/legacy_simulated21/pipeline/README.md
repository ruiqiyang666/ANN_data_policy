## 打开和运行

在本目录运行：

```powershell
python -B run.py serve --port 18765
```

浏览器打开 `http://127.0.0.1:18765`。它只监听本机回环地址。模型和数据都在 `results` 中，无需复制到其他工程。

已安装依赖记录在 `requirements.txt`。换环境时先运行 `python -m pip install -r requirements.txt`。

```powershell
python -B -m unittest test_pipeline -v
python -B run.py validate
python -B test_acceptance.py --root . --realtime
python -B run.py train
```

`train` 使用当前完整Parquet重新训练并更新报告；不会生成第二份原始数据。也可以在看板的训练页启动。正式神经网络架构尚未选定，本次使用ExtraTrees基线测试输出要求。

如确实需要重新生成，指定一个明确的新输出位置：

```powershell
python -B run.py all --target-gb 5 --output D:\明确的新输出位置
```

生成器拒绝覆盖已有 `模拟数据.parquet`。默认种子20261005。`--target-gb` 指十进制文件体积，达到目标后完成当前整支枪，再追加一个1小时截尾周期。采用未压缩Parquet，便于按列与喷枪行组读取；没有填充字节或重复文件凑大小。

### “模拟数据流”是什么

实时页的参数条表示“当前值 / 固定模拟显示范围”，不再表示偏差大小。范围从完整模拟数据的各通道最大值增加10%显示余量后向上取整，仅用于图形显示，不是设备量程或安全限值；范围不随当前窗口变化。同工况偏移σ放在特征摘要和完整细览中；停机零值不会人为拉长范围条。寿命仪表采用矢量刻度和指针，与下方寿命数字独立排版，避免遮挡。

页面原来的“回放”表示按顺序读取已经生成的1 Hz模拟记录，每个显示位置重新调用现有模型。现在改名为“模拟数据流”。1×按每秒一条的节奏查看；10×/60×每次屏幕更新前移10/60条记录，不改变原始采样率。跳转、单步和从头开始收进“定位样本”。它测试模拟时序上的预测，不代表已经连接设备，也不等同于真实逐条接入接口的在线状态验证。

实时页保留寿命小时/件数和区间、双健康、料斗压力、当前异常、未来5分钟风险、预计发生时间、原因候选与规则预警。中间的神经网络推理卡片复用原神经元可视化组件，当前标为“待接入”。右侧预测仍来自已训练的ExtraTrees四个学习器；没有把树模型包装成神经网络。正式ANN架构仍未选定。

前59条记录不足完整窗口时不输出预测；维护期间枪体寿命不可用；截尾周期无寿命真值。RUL为剩余带电小时，阈值24/12/4h。长周期图表抽取原始点并标注显示间隔，统计和完整事件清单基于完整周期。图表时间统一为UTC+8。

## 接入与输出接口

- `GET /api/overview`：清单、评估和核验摘要。
- `GET /api/series?gun=9&start=0&seconds=600&points=1000`：秒级图表窗口。
- `GET /api/snapshot?gun=9&index=1000`：指定位置的完整预测与单独标记的模拟真值。
- `GET /api/detail?gun=9&index=1000&tree=0`：真实窗口、88项特征摘要及指定树的计算路径。
- `GET /api/model-report?target=rul_hours`：与已有测试报告口径一致的分输出结果。
- `GET /api/gun-analysis?gun=9`：完整周期统计、相关性、事件和窗口聚合。
- `POST /api/live`：接受单条JSON，走真正逐条积累的 `LivePredictor`。
- `POST /api/heartbeat`：`{"now":"2026-01-01T00:01:10+08:00"}`，超过最后一条时间3秒则暂停并清空历史。调用方需要定期调用。
- `POST /api/import`：CSV检查及试推理；最多20MB、10万行。
- `POST /api/train`：重新训练当前本地基线，单任务运行。
- `GET /api/chat/status`：固定本机模型连接状态；未连接也正常返回状态。
- `POST /api/chat/message`：调用可用的本地模型；未连接返回503，不生成预设答案。

POST须加 `X-Phase2-Request: 1`，浏览器来源须为同一个本地服务；没有跨域开放。所有接口只监听127.0.0.1。

单条接入包含21项以及 `timestamp`（带时区）、`gun_id`（整数）、`seq`（全局递增整数）。可声明 `units` 字典，单位不匹配直接拒绝。拒绝重复/倒序、退役枪号重开、负值、无穷、缺失、文本伪装数值及未知状态；断秒、换枪、坏输入和超时都会清空窗口。必须重新积累60条有效记录。导入不包含标签也可以推理。

完整输出在 `outputs` 中：RUL小时和件数、90%预测区间、60秒后罐压及趋势、双健康分、异常类型和概率、未来300秒风险和预计发生时间、24/12/4h等级与原因、3σ偏离、Top-3参数模型贡献、21项输入、版本及处理耗时。模拟真值另放在 `truth`，不参与推理。

## 数据/训练语义

完整说明见上一级 `模拟与看板说明.md`。要点：原始数据1秒；训练与离线评估每60秒选择一个完整60秒窗口以限制本地资源；在线推理每秒。这是训练取窗步长，不是把原始数据改成60秒采样。

整支喷枪按编号尾数分为训练60%、校准20%、测试20%，末尾不足一组时比例略有变化。三个分区的公开残差参考片段也互不重叠。相邻窗口不跨枪混入不同集合。训练集拟合健康/压力/RUL与异常基线，校准集估计区间，最终测试集只评分；真实效果需要独立真实数据验证。

当前参数与故障机制仍是人为假设的综合设备配置。不得把合成测试指标称为产线精度，不得把模型归因当作已证实的物理因果。
