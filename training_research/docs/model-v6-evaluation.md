# Booth2 v6 研究结果与 RSI 后续路线

2026-11-20，学校 `ANN-Server`。继续完成 **9 个寿命候选 + 2 个独立预警候选**，14 个整周期留出折 + 3 个前向时间块。每个任务含 3 次内层拟合与 1 次外层拟合，共 748 次拟合调用（含基线，双种子网络内部另计）。原训练用时约 17 分 21 秒，退出 0。

**结论：v6 内层选型将末期两小时 MAE 降至 3.59h，全程 MAE 仍约 4.74h；区间明显过窄，前向时间结果未优于 v5。保留研究候选，不替换当前 18776。**

## 本轮为什么换方法

v5 在 L006（寿命约 1.90 加工小时）和 L012（约 4.41h）上有严重高估。部分周期最后才突然掉压，部分有较长下降趋势；因此本轮测试了删失加权的分位数树、CQRNN 风格直接分位网络、两成分对数正态混合网络和随机生存森林，并增加剩余寿命 KM / 已用年龄条件 KM 两个基线。

6 特征组沿用 v5 的电压余量、回落、波动、斜率及年龄；32 特征组加入累计低压、波动暴露、早期电压、加工年龄与重启状态。未将真实总寿命、未来失效时间、周期 ID、事后判定的退化类别作为输入。旧历史产品资格筛选仍有离线限制，本轮没有声称现场全链路已满足因果性。

预警头单独使用 `y_eol_60m` 训练墙钟 60 分钟风险，寿命模型预测剩余**加工小时**，避免混用时间口径。阈值取自内层未见周期，误报预算固定为 0.05/加工小时。完整协议与可复用源码在 `scripts/survival_v6/`。

## 调研带来的新方向

1. **补充可观测的退化信号。** Oerlikon Metco 的公开方案 [WO2026027724A1](https://patents.google.com/patent/WO2026027724A1/en)描述了高频电压、频谱、DeepSAD 与专家模型。示例采样为 50 kHz；当前约 1 Hz 历史不能恢复缺失的高频信息。这支持调查采集能力，不等于证明我们必须更换硬件或会获得相同效果。本文没有采用其中的自动停机动作，也未操作现场设备。
2. **SurvPFN 与预训练先验。** [2026 年论文](https://arxiv.org/abs/2606.04564)和[作者仓库](https://github.com/genepi-freiburg/SurvPFN)已核实；仓库 commit `4f26fe31efd811f546a6a3a12acd28293828ca7e` 提供官方权重入口，限制 2–10 输入特征，要求 Python ≥3.12、PyTorch ≥2.9 及固定外部依赖。已列为下一独立环境候选，本轮未下载或测试权重，不计入本轮模型数量。
3. **保留简单强基线与冻结新周期。** 本轮复杂神经网络没有稳定优势。优先持续比较 v5 AFT、v6 分位数树/生存森林，并积累新独立周期，开展区间校准和短寿命分层诊断。预先定义后续冻结集，避免继续把同一批历史当作新测试。
4. **按失效原因组织标签。** 区分渐进退化、突发异常、预防性更换和其他故障；因果可见的工况可以帮助模型，事后失效类别不能作为输入。维护受到模型建议影响时，需要记录干预，避免将成功预防的失效判作误报。

## RSI 如何承接这轮研究

RSI 的目标是把“发现错误 → 提出实验 → 独立验证 → 决定是否发布”形成长期闭环。先实施可靠的数据采集、标签和版本化训练；再让研究代理在固定预算内提出新特征/损失/模型，保留成功与失败证据。测试集、准入标准和发布权限应独立于提出模型的过程。

详细说明见 [RSI 思路](rsi-explained.md)，部署与准入条件见 [持续训练设计](continuous-learning.md)。当前自动化代码可做快照、准入和候选任务，但真实公司历史源与现场因果特征/确认标签仍未接通，定时任务未启用。学校 18776 继续使用现有发布包，模型上线仍需人工批准。

## 文件与核验口径

本机 `.phase2-release/.tmp/model-v6-20261120/`；学校 `/home/dev/Zhang/private/booth2_v6_20261120/`。`run1/report.json` 是完整评估，`predictions.npz` 是留出预测，`folds/` 是逐折模型/记录；9 个全量寿命研究模型和 2 个预警模型已保存至 `final/`，核验输出为 `verification.json`。全量模型不用于宣称留出表现。

独立核验任务正常退出 0：81,235 原点的误差/末期误差重新计算一致；17 个任务逐一检查训练/测试周期互斥及前向顺序、逐折重载模型与台账对拍、预测批次截断检查、CDF/分位有限与有序检查。留出重载最大 CDF 差小于 3e-8，寿命分位差小于 3.8e-6h；9 个全量模型分别重载一致。输入、源码与协议哈希均已核对。

v6 内层选型相对 v5 内层选型的 LOCO MAE 差为 -0.561h，探索性逐周期 bootstrap 95% 区间约 [-1.70, +0.95]h，跨过零；前向差为 +0.502h，区间约 [-1.01, +2.93]h，同样跨过零。样本数量不足以支持“稳定显著改善”。训练镜像 digest：`sha256:aac13c6c5c16050a31dcb8b1dd5bd3ff3be02326a6864116f321ba89a2ab5797`，未修改看板运行镜像。

本轮补充了 CQRNN 权重分支、混合分布中位数、经验生存尾部检查；合成删失数据检查中，分位网络/混合网络的中位数相对误差约 1.49%/0.69%，只用于实现正确性，不代表设备效果。4 个周期 12 次前缀截断的 7 项特征重算与缓存一致，14 周期时间间隔/重启核对一致。

一个经验 KM 边界错误已单独审计：测试年龄超出训练生存支持时，原实现 CDF 与其尾部分位占位约定不一致。修复只改变 KM 的概率/Brier 诊断，1944 个外层/前向原点受影响；**寿命分位、MAE、选型损失、所有学习模型和预警不变**，旧产物留在 `before-km-support-correction/`。这种不支持区域继续明确标记，不能解释为有校准保证的外推。

研究模型使用本次可信任务产出的 joblib，加载前验哈希；未接收外部不可信 pickle，也未把研究格式装入看板。最终部署需要另做安全可移植导出、运行时等价、现场因果输入、缺测降级及延迟验收。
